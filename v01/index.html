FORTRAN punched card interpreter

Punch a deck of 80-column cards holding a FORTRAN IV program, feed it to the reader, and read the output on the line printer.

Instructions

The card

ColumnsMeaning
1C or * makes the card a comment.
1–5Statement label, an unsigned integer.
6Any character except blank or 0 continues the previous statement.
7–72Statement text.
73–80Ignored (sequence numbers), with a warning.

Blanks are insignificant outside literals: G O T O 20 is GOTO 20. Only characters the IBM 029 keypunch can punch may be typed; lowercase becomes uppercase.

The deck

Program cards run through the first END card; every card after it is data. Reading past the last data card ends the job with END OF FILE ON UNIT 5. Trailing blank cards are not sent to the reader.

The language

Main program only. Names are up to six letters or digits, starting with a letter; names starting I–N are INTEGER (32-bit, division truncates), the rest REAL (single precision).

  • V = expr with + - * / **, parentheses, array elements, and .LT. .LE. .EQ. .NE. .GT. .GE. .AND. .OR. .NOT. .TRUE. .FALSE.
  • INTEGER, REAL, DIMENSION A(n), B(m,n)
  • GO TO n, GO TO (n1,n2,...), I, IF (e) n1,n2,n3, IF (cond) stmt
  • DO n I = m1, m2 [, m3] (always runs at least once), CONTINUE, STOP [n], PAUSE [n], END
  • READ (5,f) list, READ f, list, WRITE (6,f) list, PRINT f, list, and PUNCH f, list or WRITE (7,f) list for the output stacker
  • FORMAT: Iw Fw.d Ew.d nX nHtext 'text' /, repeat counts, and groups
  • SQRT ABS IABS FLOAT INT IFIX MOD AMOD SIN COS ATAN EXP ALOG ALOG10 MAX0 MIN0 AMAX1 AMIN1 SIGN

The line printer

The first character of each printed record is carriage control and is not printed: blank single space, 0 double space, - triple space, 1 new page, + overprint. So I3 printing 123 starts a new page and prints 23.

Using the simulator

Load a sample or type cards, click a card to see its holes, and press Run deck. Punched cards land in the output stacker; load them into the editor and run again to read them as data. In the editor, Enter adds a card, Backspace on an empty card removes it, the arrow keys move between cards, and pasting several lines makes several cards.

The sieve generator

The last sample generates Xenakis-style sieves. The residual class m@s is every integer x with x−s divisible by m. Its data is one card with MODE, N, LIMIT, then N cards with M, S, all in 5-column fields. Mode 1 is the union of the classes, 2 the intersection, 3 the complement of the union; N is 1 to 10, and the integers 0 to LIMIT−1 are tested. Each member is printed with its interval from the previous one and punched on its own card. The sample data is 5@2 | 5@3 over 0 to 19.
