# MPCS 51238 - Assignment 1

This repository contains Assignment 1 for MPCS 51238, *Design, Build, Ship*. It is a collection of web pages centered around FORTRAN, punch cards, and Xenakis's sieves. The finished page takes this concept and extends it into a complete skeumorph of a personal space.

The live websites may be found [here](https://mpcs-51238-assignment-1-one.vercel.app/).
